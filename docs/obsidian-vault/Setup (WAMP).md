# Setup (WAMP)

## 1. Get the repository and set up remotes

All developers share one repository: `https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git` (remote name **`upstream`**). Scripts, the pre-push hook, and [[Team Sync]] all assume that name.

### Option A — clone the shared repo directly (you were added as a collaborator)
```powershell
git clone https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git hospital_billing
cd hospital_billing
git remote rename origin upstream
git fetch upstream --prune
git checkout zur-test
```

### Option B — you already cloned a fork (remote `origin` is yours)
```powershell
git remote add upstream https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git
git fetch upstream --prune
git checkout -B zur-test upstream/zur-test
git branch --set-upstream-to=upstream/zur-test zur-test
```

### Verify
`upstream` must point to `Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git`:
```powershell
git remote -v
```

### One-time setup (both options)
```powershell
git config pull.rebase true
git config rebase.autoStash true
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install-hooks.ps1"
```
This makes plain `git pull` a rebase, and installs the pre-push hook that keeps you in sync automatically (see [[Team Sync]]).

## 2. Place the project
Put the folder under the WAMP web root, e.g. `C:\wamp64\www\hospital_billing`. The URL will mirror the folder name:
`http://localhost/hospital_billing/login.php`

(Names with spaces/brackets are URL-encoded: `http://localhost/[1]%20hospital_billing/login.php`.)

If you cloned somewhere else, move or re-clone the folder into the web root.

## 3. Start services
Open the WAMP tray menu and start **Apache** and **MySQL**.

## 4. Create and import the database
1. Open `http://localhost/phpmyadmin`.
2. Create a database named `hospital_db` with collation `utf8mb4_unicode_ci`.
3. Select it → **Import** → choose `migrations/hospital_db.sql` → **Go**.
4. Apply any newer migrations listed in [[Database Migrations]].

## 5. Configure the connection
Credentials live in `config/db_connect.php`. WAMP defaults:
```php
$db_host = '127.0.0.1';
$db_port = '3306';
$db_name = 'hospital_db';
$db_user = 'root';
$db_pass = '';
```

## 6. Sign in
Open `login.php` and use a seeded account (see the project `README.md`). Insert additional accounts with `password_hash()` — never plain text.

## 7. After changing front-end assets
The shell loads `style.css?v=N` and `main.js?v=N`, and module imports use the same `?v=N`. When you edit CSS/JS, bump `N` in `admin_dashboard.html` (and the imports) so browsers fetch fresh files, or hard-refresh with **Ctrl+F5**.

## 8. Keep the database in sync with migrations
After every repo sync, check `migrations/` for new or changed SQL and apply it to `hospital_db` before running the app. Full routine and checklist: [[Database Migrations]].

## Troubleshooting
- **500 on API calls** — check Apache/PHP error log and the MySQL connection values.
- **Login always fails** — confirm the `users.password_hash` was generated by PHP `password_hash()`.
- **Tables empty in UI** — check the browser console; API requires an authenticated session and Administrator role.
- **Push rejected / hook says diverged** — run `git pull --rebase`, then push again (see [[Team Sync]]).
