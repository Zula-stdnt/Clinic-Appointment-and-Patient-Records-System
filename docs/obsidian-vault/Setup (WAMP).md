# Setup (WAMP)

Follow these steps to install and run the project on a Windows computer using **WAMP** (or **XAMPP**).

## 1. Place the project
Copy the project folder into your web server's public root folder—for example, `C:\wamp64\www\hospital_billing` in WAMP (or `C:\xampp\htdocs\...` in XAMPP). Your browser address will match the folder name:
`http://localhost/hospital_billing/login.php`

*(If your folder name contains spaces or brackets, the browser encodes them in the address bar—for example, `http://localhost/[1]%20hospital_billing/login.php`.)*

## 2. Start services
Open the WAMP tray menu (or XAMPP Control Panel) and start both **Apache** (the web server) and **MySQL** (the database server).

## 3. Create and import the database
1. Open `http://localhost/phpmyadmin` in your browser.
2. Create a new database named `hospital_db` with the character collation set to `utf8mb4_unicode_ci`.
3. Click `hospital_db` in the left sidebar → click the **Import** tab → choose the file `migrations/hospital_db.sql` → click **Go**. This sets up all tables and sample user accounts.

## 4. Configure the connection
Database login settings live in `config/db_connect.php`. The default settings for WAMP and XAMPP are:
```php
$db_host = '127.0.0.1';
$db_port = '3306';
$db_name = 'hospital_db';
$db_user = 'root';
$db_pass = '';
```

## 5. Sign in
Open `login.php` (or `login.html`) in your browser and sign in using one of the pre-loaded sample accounts listed in `README.md`. If you ever insert extra accounts directly into the database, always scramble the password with PHP's `password_hash()` function—never type a plain-text password into the `password_hash` column.

## 6. After changing front-end assets
To stop browsers from showing outdated copies of CSS or JavaScript files, the page shells load `style.css?v=N` and `main.js?v=N` (currently `?v=22`), and JavaScript module imports use the same version number. Whenever you edit a CSS or JS file, increase `N` in the dashboard shell and module imports so the browser downloads the newest file, or press **Ctrl+F5** in your browser to force a full refresh.

## Troubleshooting
- **500 error on API calls** — Check the Apache/PHP error log and verify that MySQL is running and the credentials in `config/db_connect.php` match your setup.
- **Login always fails** — Confirm that the database was imported from `migrations/hospital_db.sql` and that `users.password_hash` contains a valid bcrypt hash generated by `password_hash()`.
- **Tables look empty in the UI** — Open the browser developer console (`F12`); remember that administrator tables require an active login session with the `Administrator` role.
