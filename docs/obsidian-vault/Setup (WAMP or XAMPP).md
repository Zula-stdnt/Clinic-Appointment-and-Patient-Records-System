# Setup (WAMP or XAMPP)

The project runs on either stack — use whichever you have installed. Replace example paths with yours.

| | WAMP | XAMPP |
| --- | --- | --- |
| Web root | `C:\wamp64\www\` | `C:\xampp\htdocs\` |
| MySQL client | `C:\wamp64\bin\mysql\mysql8.4.7\bin\mysql.exe` | `C:\xampp\mysql\bin\mysql.exe` |
| Start services | WAMP tray icon | XAMPP Control Panel |
| phpMyAdmin | `http://localhost/phpmyadmin` | `http://localhost/phpmyadmin` |
| DB credentials | `root` / empty password, port 3306 | `root` / empty password, port 3306 |

## 1. Get the repository and set up remotes

All developers share one repository: `https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git` (remote name **`upstream`**). Scripts, the pre-push hook, and [[Team Sync]] all assume that name.

### Option A — clone the shared repo directly (you were added as a collaborator)
```powershell
git clone https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git hospital_billing
cd hospital_billing
git remote rename origin upstream
git fetch upstream --prune
git checkout zur-test
```

### Option B — you already cloned a fork (remote `origin` is yours)
```powershell
git remote add upstream https://github.com/Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git
git fetch upstream --prune
git checkout -B zur-test upstream/zur-test
git branch --set-upstream-to=upstream/zur-test zur-test
```

### Verify
`upstream` must point to `Zula-stdnt/Hospital-Billing-and-Patient-Information-System.git`:
```powershell
git remote -v
```

### One-time setup (both options)
```powershell
git config pull.rebase true
git config rebase.autoStash true
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install-hooks.ps1"
```
This makes plain `git pull` a rebase, and installs the pre-push hook that keeps you in sync automatically (see [[Team Sync]]).

## 2. Place the project
Put the folder under your server's web root so the URL mirrors the folder name:
- WAMP: `C:\wamp64\www\hospital_billing`
- XAMPP: `C:\xampp\htdocs\hospital_billing`

Then open `http://localhost/hospital_billing/login.html`.

(Names with spaces/brackets are URL-encoded: `http://localhost/[1]%20hospital_billing/login.html`.)

If you cloned somewhere else, move or re-clone the folder into the web root.

## 3. Start services
Start **Apache** and **MySQL**:
- WAMP: left-click the tray icon, start both.
- XAMPP: open the XAMPP Control Panel, click **Start** for Apache and MySQL.

## 4. Create and import the database
1. Open `http://localhost/phpmyadmin`.
2. Create a database named `hospital_db` with collation `utf8mb4_unicode_ci`.
3. Select it → **Import** → choose `setup/schema.sql` → **Go**.
4. Repeat for `setup/seeds.sql`.
5. From a terminal, run `php setup/bootstrap_admin.php` and follow the interactive secure prompts.

> **Note:** Fresh installs must **not** replay historical migrations from the `migrations/` folder. The `setup/schema.sql` file already incorporates all active structural updates.

## 5. Configure the connection
Credentials live in `config/db_connect.php`. Defaults on both WAMP and XAMPP:
```php
$db_host = '127.0.0.1';
$db_port = '3306';
$db_name = 'hospital_db';
$db_user = 'root';
$db_pass = '';
```

## 6. Sign in
Open `login.html` and use the admin account you just bootstrapped. Create additional accounts through the Admin Dashboard interface instead of inserting them directly.

## 7. After changing front-end assets
The shell loads `style.css?v=N` and `main.js?v=N`, and module imports use the same `?v=N`. When you edit CSS/JS, bump `N` in `admin_dashboard.html` (and the imports) so browsers fetch fresh files, or hard-refresh with **Ctrl+F5**.

## 8. Keep the database in sync with migrations
After every repo sync, inspect `migrations/` for new SQL. **Do not apply migrations automatically.** Destructive scripts (like `006`) must only be applied to an existing database after verifying the exact baseline schema, creating a full backup, and obtaining manual approval. Full routine and checklist: [[Database Migrations]].

## Troubleshooting
- **500 on API calls** — check the Apache/PHP error log (WAMP: `C:\wamp64\logs\`; XAMPP: `C:\xampp\apache\logs\` and `C:\xampp\php\logs\`) and the MySQL connection values.
- **Login always fails** — confirm the `users.password_hash` was generated by PHP `password_hash()`.
- **Tables empty in UI** — check the browser console; API requires an authenticated session and Administrator role.
- **Push rejected / hook says diverged** — run `git pull --rebase`, then push again (see [[Team Sync]]).
