## 1. Lesson Summary

### Main Idea

React is a JavaScript library for building user interfaces from components. **Next.js** is a React framework that adds routing conventions and tools for rendering, data loading, and application development. In the App Router, pages and layouts are Server Components by default, while Client Components provide browser APIs and interactivity. Rendering behavior depends on the route and configuration; using Next.js does not by itself guarantee a particular SEO outcome.

### 1. React Components and JSX

* **Components:** Reusable pieces of UI, such as a button, navigation bar, or page.
* **JSX:** A syntax extension that lets you describe UI with markup-like syntax inside JavaScript.

### 2. Installation and CLI Commands

Install **Node.js** before creating a Next.js project. Use a terminal and a package manager to create and run the project.

* **Create a project:** `npx create-next-app@latest`
* **During setup:** Choose options such as TypeScript, ESLint, Tailwind CSS, and the App Router. Follow the requirements of your course or project.
* **Start development:** Change to the project directory and run `npm run dev`. The development server usually opens at `http://localhost:3000`.

### 3. Core Folder Structure

* **`app/`:** Used by the App Router. Files such as `page.js` define route UI and `layout.js` defines shared structure. A folder by itself does not create a visible page; a route needs the relevant special file, such as `page.js`.
* **`pages/`:** Used by the Pages Router, an alternative routing system supported by Next.js.
* **`public/`:** Stores static assets. A file at `public/photo.jpg` is referenced with a root-relative path such as `/photo.jpg`.
* **`package.json`:** Contains project scripts and dependency declarations. Use the package manager to add or update dependencies; do not edit installed files inside `node_modules` directly.

## 2. Coding Writing Style

### Project Structure and Conventions

* In an App Router project, route UI and layouts are organized under `app/`; a Pages Router project uses `pages/`.
* React component names conventionally start with a capital letter (for example, `MyButton` or `ProfileAvatar`) so JSX recognizes them as components.
* Keep files organized by responsibility. Use the route files generated by the selected router for their intended roles.
* Use `className` rather than the HTML `class` attribute in JSX. Global CSS is typically imported from the root layout; CSS Modules can be imported by components.

### Component Example

A function declaration or arrow function can define a component. This example uses a function declaration:

```javascript
export default function HelloWorld() {
  return (
    <main>
      <h1>Hello world</h1>
    </main>
  );
}
```

### Images

Next.js provides an optimized `<Image />` component, but a native `<img>` can still be appropriate. Choose based on the needs of the image and project. The `Image` component requires `alt` text and generally needs `width` and `height`, unless the image is statically imported or uses `fill`. When using the default optimizer for remote images, configure the allowed remote hosts.

## 3. Quick Review

### Important Commands

```bash
npx create-next-app@latest
cd your-project-name
npm run dev
```

### Core Idea

**Next.js is a React framework with file-based routing conventions and server/client rendering tools. Learn the router selected for the project and use Client Components where browser-side interactivity is needed.**
